# Матрёшка: Telegram Mini App

Мини-приложение в Telegram для детского центра «Матрёшка» (Одинцово). Через него родители смотрят информацию о центре, записываются на экскурсии, занятия, к специалистам и на услугу «Няня на час», а бот присылает подтверждения и напоминания.

## Что умеет

**Приложение**

- **Главная**: афиша мероприятий, кнопка «Записаться на экскурсию», личное расписание с отменой записей, контакты администратора.
- **Детский сад**: форматы «Полный день», «Группа кратковременного пребывания», «Сад выходного дня» (запись на экскурсию выбирается только по дням: пн–пт или сб–вс) и «Няня на час».
- **Няня на час**: выбор дня, времени и одной из нянь. Няня, которую уже забронировал другой человек, недоступна.
- **Занятия**: каталог по возрастным группам и запись.
- **Логопед / нейропсихолог**: запись на консультацию.

**Бот**

- Сообщение «✅ Вы записаны» сразу после записи и «❌ Запись отменена» после отмены.
- Напоминания: за сутки и за 2 часа до начала (для записей «на день» только за сутки).
- Приветствие по команде `/start`.

**Правила записи** (настраиваются в `bookingStore.js`)

- Запись длится 1 час, записаться можно не позднее чем за 2 часа до начала.
- Не более 5 активных записей, не более 28 дней вперёд.
- Отмена не позднее чем за 2 часа, не более 3 отмен в сутки.
- Нельзя записаться на пересекающееся время.

## Как это устроено

```
Родитель в Telegram
   │  открывает мини-приложение (React + Vite, GitHub Pages)
   ▼
App.jsx ──POST/GET──▶ Google Apps Script (Code.gs) ◀── триггер каждые 10 минут
                          │        │                   (напоминания)
                          ▼        ▼
                  Google Таблица   Telegram Bot API ──▶ сообщения родителям
                  (записи)
```

- **Интерфейс** отдельно от сервера: сайт лежит на GitHub Pages, вся серверная логика в Google Apps Script.
- **Google Таблица** служит базой данных: лист «Записи» хранит все записи и отмены.
- **Записи на устройстве.** Список записей хранится ещё и на телефоне пользователя (Telegram CloudStorage, запасной вариант localStorage). Источником правды о занятости нянь служит таблица.
- **Уведомления** отправляет тот же Apps Script. Бот на Python нужен только для ответа на `/start` и не участвует в записях и напоминаниях.

## Структура проекта

```
├── index.html              точка входа, подключает telegram-web-app.js
├── public/
│   ├── favicon.svg
│   ├── call.html           страница с кнопкой «Позвонить» (в Telegram ссылки tel: не открываются)
│   └── privacy.html        политика конфиденциальности (если используется своя)
├── src/
│   ├── main.jsx            запуск React
│   ├── App.jsx             все экраны, формы и модальные окна
│   ├── App.css             стили приложения
│   ├── index.css           базовые стили
│   ├── bookingStore.js     правила записи, даты, хранение на устройстве
│   ├── scheduleData.js     расписание экскурсий, нянь, специалистов
│   └── assets/             иконки и иллюстрации (SVG)
├── Code.gs                 серверная часть для Google Apps Script
└── tg_bot.ipynb            бот на Python: только ответ на /start (токен берётся из .env)
```

Токен для `tg_bot.ipynb` лежит в файле `.env` (`TG_TOKEN=...`). Не добавляйте `.env` в репозиторий.

## Запуск на компьютере

Нужен Node.js.

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в папку dist
```

Вне Telegram приложение откроется в браузере, но без Telegram ID и ника. Уведомления в таком режиме работать не будут. Проверять нужно из самого Telegram.

## Публикация приложения

Сайт лежит на GitHub Pages. Проверьте, что в `vite.config.js` указан `base` с именем репозитория, например `base: '/tg-mini-app/'`. После публикации адрес прописывается в BotFather как адрес мини-приложения (кнопка меню бота или Direct Link).

Мини-приложение нужно открывать через кнопку меню бота или Direct Link. Если открыть его кнопкой обычной клавиатуры, Telegram не передаст данные пользователя, и уведомления слать будет некому.

## Настройка серверной части (Google Apps Script)

1. Создайте Google Таблицу и откройте в ней Extensions → Apps Script. Скрипт должен быть привязан к этой таблице.
2. Вставьте содержимое `Code.gs`.
3. Project Settings → Time zone: Moscow.
4. Project Settings → Script properties:

   | Свойство | Значение |
   |---|---|
   | `BOT_TOKEN` | токен бота от @BotFather |

5. Запустите функцию `setup` и разрешите доступ. Она создаёт таймер на `sendReminders` (раз в 10 минут).
6. Deploy → New deployment → Web app. Execute as: Me, Who has access: Anyone. Скопируйте адрес и вставьте его в `GOOGLE_WEBHOOK_URL` в начале `App.jsx`.
7. После каждого изменения `Code.gs`: Deploy → Manage deployments → карандаш → New version → Deploy. Без этого сайт продолжит работать со старым кодом (таймер использует сохранённый код сразу).

**Токен бота нельзя хранить ни в `App.jsx`, ни в репозитории.** Только в Script properties. Если токен где-то засветился, отзовите его в @BotFather (Revoke) и вставьте новый в `BOT_TOKEN`.

### Служебные функции

| Функция | Для чего |
|---|---|
| `diagnose` | проверяет токен, триггер, записи без Telegram ID |
| `debugReminders` | показывает, как скрипт видит активные записи |
| `testSend` | шлёт тестовое сообщение тому, кто записывался последним |
| `removeBot` | отключает webhook и команды бота (нужна, только если ранее запускали `setupBot`) |

## Таблица «Записи»

| № | Колонка | Описание |
|---|---|---|
| 1 | Создано | когда сделана запись |
| 2–3 | Имя, Телефон | из профиля |
| 4 | Что | название услуги |
| 5–6 | Дата, Время | время начала по Москве |
| 7 | Статус | «Записан» или «Отменена» |
| 8 | Отменено | когда отменена |
| 9 | Telegram ID | кому слать уведомления |
| 10 | ID записи | `вид:объект:дата:время`, для нянь `nanny:n1:2026-11-16:10:00` |
| 11 | Согласие на ПДн | время согласия |
| 12–13 | Напоминание за сутки / за 2 часа | когда отправлено, «—» если не нужно |
| 14 | Весь день | «1» для записей без времени |
| 15 | Ник Telegram | `@username`, если он есть |

Что можно делать с таблицей: удалять тестовые строки целиком. Чего нельзя: удалять, добавлять и переставлять колонки (скрипт ищет данные по номеру колонки), удалять строку заголовков и актуальные записи со статусом «Записан».

## Как менять содержимое

| Что нужно изменить | Где |
|---|---|
| Няни (ФИО, стаж) и их график | `NANNIES` и `NANNY_RULES` в `scheduleData.js`. `id` нельзя менять после запуска |
| Дни записи на экскурсии в саду | `DAY_VISITS` в `scheduleData.js` |
| Время экскурсий с главной кнопки | `TOUR` в `scheduleData.js` |
| Время специалистов | `SPECIALISTS` в `scheduleData.js` |
| Афиша мероприятий | массив `events` в `App.jsx` |
| Форматы сада, цены, описания | массив `formats` в `App.jsx` |
| Специалисты и тексты | массив `specialists` в `App.jsx` |
| Правила записи (лимиты, сроки) | константы в начале `bookingStore.js` |
| Адрес, телефон администратора | `bookingStore.js` и `Code.gs` (в обоих местах) |
| Ссылка на политику конфиденциальности | `PRIVACY_URL` в `App.jsx` (сейчас там временная ссылка) |

## Если что-то не работает

- **Пустой экран после заставки.** Откройте консоль браузера (F12) в режиме `npm run dev`: там будет красная ошибка. Частая причина: удалена или переименована функция, которую использует интерфейс.
- **Не приходят сообщения.** Запустите `diagnose` и проверьте по порядку: задан ли `BOT_TOKEN`, рабочий ли он, нажал ли человек Start у бота, есть ли у записи Telegram ID, создан ли триггер (вкладка Triggers), были ли запуски `sendReminders` (вкладка Executions).
- **Напоминание не пришло, хотя триггер работает.** Запустите `debugReminders`: он покажет, сколько минут до начала и что стоит в колонках напоминаний.
- **Бот в ноутбуке не отвечает на /start.** Если когда-то запускали `setupBot`, выполните `removeBot`: пока webhook включён, опрос из ноутбука не работает.
- **Иконки появляются с задержкой.** Все картинки предзагружаются на заставке. Если нужно ещё быстрее, добавьте в `vite.config.js` в `build` параметр `assetsInlineLimit: 100000`.
- **Время напоминаний сдвинуто.** Скрипт всегда считает время записи по Москве. При тестах из другого часового пояса моменты отправки будут отличаться от ожидаемых.
